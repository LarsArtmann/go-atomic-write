## Requirements

- Go 1.26 or later
- An active Go module (`go.mod`)

## Install

Run this in your project directory:

```bash
go get github.com/larsartmann/go-atomic-write@latest
```

## Quick Usage

```go
package main

import (
	"errors"
	"fmt"

	atomicwrite "github.com/larsartmann/go-atomic-write"
)

func main() {
	path := "/path/to/config.json"

	fingerprint, err := atomicwrite.FingerprintFile(path)
	if err != nil {
		panic(err)
	}

	newData := []byte(`{"updated": true}`)

	err = atomicwrite.WriteVerified(path, newData, fingerprint)
	if errors.Is(err, atomicwrite.ErrConcurrentModification) {
		fmt.Println("file was modified concurrently — re-read and retry")
		return
	}
	if err != nil {
		panic(err)
	}
}
```
